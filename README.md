# Customer-Churn-report
A bank is experiencing a high rate of customer churn and wants to understand the key factors contributing to this problem. The task is to produce a report that analyses the historical data set of customer information from the Customer-Churn-Records.csv and identify patterns in the data that would help the bank address the issue.
